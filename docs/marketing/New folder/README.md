### Export PDF (Windows)

1. Open `augusta-search-ad-SUBMIT.html` in **Chrome** (internet needed once for QR).
2. Wait ~1 s for QR code bottom-right.
3. **Ctrl+P** → Save as PDF
4. Paper: **Custom 93 mm × 131 mm** (or A4 + crop in Acrobat)
5. Margins: **None** · Scale: **100%** · **Background graphics: ON**
6. Save as: **`AugustaSearch_QuarterPage_SES.pdf`**

### Email to publisher
